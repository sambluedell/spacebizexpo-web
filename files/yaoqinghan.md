# 中国遥感应用协会 中国通信工业协会

举办意义：

随着全球商业航天产业高速发展，我国“十五五”规划对航空航天发展做出战略性规划蓝图，推动商业航天、太空旅游、太空数智基础设施、太空资源开发、太空交通管理快速发展。据不完全统计，我国商业航天领域近5年投资总额超1000亿,多家机构预计2026年将迎来商业航天企业上市潮。20多个省区市出台了涉及商业航天的产业政策。空天信息和商业航天及太空经济进入快速布局和发展。预计商业航天和太空产业未来五年产值近十万亿；

举办商业航天生态合作大会暨2026深圳商业航天展览会是进一步推进空天信息建设和商业航天快速发展，推动科技创新、产业融合及商业应用！本届大会将侧重商业航天、空间探测、太空制造、卫星应用等深入交流和展示，倾力打造集商业航天研究、设计、制造、试验、总装、测试、发射、在轨、离轨、应用、回收、开发、投融资和供应链为一体的产业链盛会；推动商业航天、空天科技与卫星应用技术领域的高质量发展。

主办单位：中国遥感应用协会、中国通信工业协会

# 三、参与价值：

1、产业价值：全产业链集中推动上下游企业“面对面”对接，促进供应链协同化、共享平台共资源大幅压缩企业研发周期。技术迭代与创新孵化：集中展示前沿成果，加速从实验室到产业化的转化。

2. 商业价值：资本对接与市场拓展吸引银行、保险、创投、产业基金等入场，提供融资、保险、供应链金融、投贷联动等定制化方案，破解商业航天“高投入、长周期”的资金瓶颈。

3、订单与合作高效转化：成为全球采购商、运营商、政府机构的集中采购平台，快速达成发射服务、卫星组网、数据应用、技术联合研发等合作意向。

4、培育下游应用市场：将航天技术与智慧城市、农业、金融、应急、环保等领域结合，展示卫星遥感、通信、导航的商业化价值，拉动终端需求。

5、国际价值：资源高效链接：吸引国际企业、投资机构参与，在卫星频率轨道、太空交通规则、数据共享等议题上发声，推动构建开放、包容、共赢的太空新秩序。

6、打造区域产业高地：吸引企业、人才、资本集聚，形成“航天产业集群”，展示商业航天作为国家航天体系重要组成部分的实力，提升整体航天竞争力。

7、时代价值：推动太空经济商业化、构建新航天共同体：
